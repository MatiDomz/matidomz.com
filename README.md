# matidomz.com

Personal website and infrastructure lab for **Mati Domz**.

The goal of this repository is not only to host a portfolio, but to use the site itself as a hands-on environment for learning and demonstrating professional application delivery practices.

## Planned stack

- GitHub Codespaces for a reproducible development environment
- Docker for application packaging
- GitHub Actions for CI/CD
- Azure Container Registry for image storage
- Azure Container Apps for runtime and revisions
- Cloudflare for DNS and domain management
- Health checks, observability, rollback and deployment experiments

## Development principles

- The repository is the source of truth.
- The development environment must be reproducible.
- Secrets never belong in Git.
- Production should contain only what the application needs to run.
- Infrastructure and deployment decisions should be documented as the project evolves.
